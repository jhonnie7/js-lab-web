SAP Cloud Connector on SLES

Hands-on notes from my own lab: SAP Cloud Connector 2.16.2 on SLES for SAP Applications 15 SP6, connected to an SAP BTP trial subaccount, with a master and a shadow instance and an ABAP system as the backend. Three guides on SAP Community, in the order I would read them.

The lab

  • Cloud Connector : 2.16.2, upgraded to 2.19.1 in Part 3
  • OS : SLES for SAP Applications 15 SP6, VMs on Proxmox
  • Instances : master (scc) and shadow (scc-shadow)
  • Backend : SAP NetWeaver 7.5 ABAP (SID NW7) on MaxDB
  • BTP : trial subaccount with HTTP and HTTPS system mappings

PART 2 · HIGH AVAILABILITY

SAP Cloud Connector on SLES - Part 2: High Availability with a Shadow Instance and Failover Tests

Adding a shadow instance next to the master, configuring high availability and doing a controlled role switch. Then two failure tests: powering off the shadow, and abruptly powering off the active master. The master role moved to the other instance in about a minute, with the subaccount connection and system mapping staying green.
